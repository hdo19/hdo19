HADOOR TECH - InfinityFree deployment

1) Upload ALL files inside this folder to the public_html (or htdocs) folder.
2) Make sure .htaccess is uploaded too. It is a hidden file, so enable showing hidden files in the File Manager if needed.
3) Keep article.html, article.js, tutorial-data.js and firebase-config.js in the same root folder as index.html.
4) Article links use:
   /article/bsod-windows
   /article/bootloop-android
   /article/kali-apt
5) Do not create an /article folder. .htaccess rewrites /article/<id> to article.html.
6) After upload, test the homepage first, then click a Windows article. Also test opening the article URL directly in a new tab.
